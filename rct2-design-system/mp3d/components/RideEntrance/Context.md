# RideEntrance

The classic RCT2 ride ENTRANCE / EXIT hut, modelled on the original entrance assets: a compact peaked-roof pass-through booth with dark timber corner posts, cream wall panels and a saddle roof over an open doorway in both the front and back walls (a peep walks straight through onto the ride platform). The ENTRANCE kind carries RCT2's tall decorative FALSE FRONT — a stepped marquee board raised over the front gable that climbs well ABOVE the roof ridge (base board → shoulder → cap → timber coping), with the GREEN sign band mounted high on the board and a warm lamp finial on top; the front roof overhang is trimmed so the raked edge tucks behind the board. The EXIT kind keeps a low plain front: flatter roof and a RED band hung on struts at lintel height. Green + tall = entrance, red + low = exit, at a glance.

Sign lettering is a recessed LED DOT-MATRIX screen (`mountLedScreen` / `ledScreenTexture` in `index.tsx`): a procedural CanvasTexture — dark bezel with a deterministic hashed-sine speckle behind a full grid of pixel squares, lit squares forming the word via a hand-built 5×7 glyph font (no canvas `fillText`, no font dependency, same "draw the glyphs yourself" spirit as NeonSign's vector font). The texture is applied as both `map` and `emissiveMap` on a thin plane flush with the sign band's face, tucked just under the white frame stripes' proud lip so it reads as inset, not floating. Entrance glows green ("ENTRANCE", `0x39ff6a`), exit glows red ("EXIT", `0xff3b30`) — matching each band's own hue. `emissiveIntensity` is gated by `nightKOf` (smoothstep 0.16 → ~2.26) exactly like the lamp finials, so the sign reads as ordinary printed colour by day and lights up like a real LED sign after dark.

`buildRideEntrance(t, { kind?: 'entrance' | 'exit' })` → `{ group, doorway }` where `doorway` is the local ground-level walk-through point in front of the hut (`[0, 0, 0.66]`, also exported as `ENTRANCE_DOORWAY`) — the GameManager routes peeps through it (queue → doorway → ride platform, and the reverse through an exit hut). The hut faces local +z; footprint ≈ 1.1 × 0.95, doorway 0.42 wide, sized for 0.5-scale peeps.

Original three.js composition on the shared Stage; proportions and the green/red sign convention referenced from the RCT2 entrance sprites, realistic palette only.
