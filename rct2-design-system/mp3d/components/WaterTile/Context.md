# WaterTile

Animated water surface with a custom GLSL wave + Fresnel + sparkle shader (matte park water, NATURAL desaturated palette — 2026-07 THIRD pass: pass one fixed navy dead-patch grey by going to a 100%-saturated electric cyan, which read as neon; pass two cut saturation to ~50-80% (0x7dc9cf/0x42899a/0x28526c) but still read as vivid tropical-pool cyan-turquoise; this pass cuts saturation again to ~30-38% AND rotates hue off pure cyan/turquoise toward a more natural blue-grey (with a touch of green in the shallows) — shallow 0x7ab8b8 / mid 0x3f6c7d / deep 0x243e51 — so the water reads like a real lake/pool lit by the sky rather than a glowing tank or swimming pool. Raised opacity floor 0.78, deep stays clearly blue, never slate/black; a `uNight` uniform driven by `nightKOf` inside every update moonlight-dims the sheet, ribbon and skirt after dark). Highlights are deliberately SUBTLE, toned down further each pass: glint/twinkle/foam colours are all anchored to the LOCAL body colour (glint only ~16% toward white — was 22% — glint weight 0.075 — was 0.10 — twinkle 0.035 — was 0.05 — foam mixed via base), and the Fresnel rim tint was desaturated from a saturated sky-blue to a near-neutral pale and weighted down (0.05, was 0.08), so they read as shimmer ~10-18% lighter than the body — never near-white or saturated-blue gloss patches. Exports: `buildWater(t, size, seg, radius, skirt?, amp?, waviness?)` — square sheet, optionally radius-clipped to a round pool; `amp` scales the vertex swell only (default 1 ≈ ±0.30 — shallow basins pass a smaller amp so troughs never dip below their floor and show flat dead patches; the tile preview pool uses 0.22); `waviness` (default 1 = current look) is the ONE calm-water knob: it composes with `amp` on the swell (total displacement = amp × waviness) AND scales the shader wave field itself — ripple-normal shimmer, colour churn, crest foam, twinkle — so ~0.4 reads as a still ornamental pool (Fountain basin uses amp 0.6 × waviness 0.4, its bowl 0.12 × 0.5); clipped pools grow a perimeter DEPTH SKIRT by default (a short translucent deep-gradient band hanging from the rim, so side/low views read a volume of water instead of a paper-thin plane; `skirt: number | false` overrides). `buildWaterMaterial(t, { radius, amp, ribbonLength, waviness })` — the shared shader. **Fog (2026-07):** the water is drawn by a raw `ShaderMaterial`, which three never plumbs `scene.fog` into — so at long render distances the sheet stayed fully saturated while every MeshStandard surface around it hazed out (distant park water read as a bright blue slab with a hard edge at the fog wall / camera far plane). The sheet, ribbon and skirt shaders now carry three's LINEAR fog (`smoothstep(near, far, viewDepth)`, colour only, applied after the night dim so the water still reads translucent up close), and every builder's `update()` calls the new `syncWaterFog(mesh, material)` to copy the live `scene.fog` into the uniforms each frame (no-op haze when the scene has no fog or uses FogExp2). `buildWaterRibbon(t, points, width, { amp, waviness })` — ONE continuous water ribbon along spline frame samples (`{ p, side, up? }`), local coords = (across, alongArc) with along-arc wave frequencies quantized to whole cycles so closed loops wrap seamlessly (used by RiverRapids' channel).

Built with three.js on the shared Stage; modelled from the authentic RCT2 sprite.
